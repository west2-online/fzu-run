### 编程题

#### T1

（此处省略情景引入）求给定的正整数数列中首次出现重复的数字，若没有重复请输出`NONE`。（5pt）

**输入格式**

第一行输入一个正整数`T`，表示测试的数据组数；接下来`T`行，每行输入若干个以空格分割且小于等于1000的正整数，若为`-1`则表示数列结束。

**输出格式**

对于每一组数据，输出一行表示首次重复出现的数字，若无重复请输出`NONE`。

#### T2

（省略情景）给一些数据（不超过1000个），范围[-10^6, 10^6]，求平均值（向下取整）、最大值、最小值，并按顺序输出所有超过平均值两倍的数据。（5pt）

**输入格式**

第一行输入一个正整数`n`，第二行输入`n`个正整数表示这些数据。

**输出格式**

第一行输出平均值（向下取整）、最大值、最小值，第二行按顺序输出所有超过平均值两倍的数据（空格分割）。

#### T3

给定两个字符串`s1` `s2`，校验`s1`能否通过一次操作翻转部分子串转换为`s2`。（10pt）

**输入格式**

第一行输入一个正整数`T`，表示测试的数据组数；对于每组，输入两行字符串分别表示`s1`和`s2`。

**输出格式**

对于每一组数据，若满足题述校验要求，则输出一行`Yes`，否则输出一行`No`。

#### T4

给定正整数`a` `b`（笔者：忘记范围是多少了）。求是否存在`x`为`a`的倍数且不为`b`的倍数（`x>a`），`y`为`b`的倍数且不为`a`的倍数（`y>b`），使得`x+y`最小。（10pt）

**输入格式**

第一行输入一个正整数`T`，表示测试的数据组数；接下来`T`行，每行依次输入`a` `b`（以空格分割）。

**输出格式**

对于每一组数据，输出一行求得的`x` `y`，以空格分割；若无法达成条件，则输出一行`0` `0`。

#### T5

定于对于整数数列`A`，`f(A)`为`A`所有相邻两项之差绝对值的总和。现要求删去其中一个数形成新数列，求删去后`f(A')`的最小值、删数的方案数，以及按顺序输出这些方案中删去的数对应的下标（从1开始）。（10pt）

**输入格式**

第一行输入一个正整数`T`，表示测试的数据组数；对于每组数据，第一行输入`n`表示数列的长度，第二行输入`n`个整数，表示数列内容。

**输出格式**

对于每一组数据，第一行输出两个整数`f(A')` `m`，其中`m`表示删数的方案数；第二行输出`m`个整数，表示每一种方案删去的数对应的下标（从1开始）。

#### T6

有6个骰子，每次投掷它们得到6个1~6的点数。按以下规则记分：

| 点数       | 得分计算方式                              |
|------------|-------------------------------------------|
| 1          | 100                                       |
| 5          | 50                                        |
| 12345      | 500                                       |
| 23456      | 750                                       |
| 123456     | 1500                                      |
| 三个同点数 | 若为`1`则记`1000`分，否则记`此点数*100`分 |
| 四个同点数 | "三个同点数"的分值两倍                    |
| 五个同点数 | "四个同点数"的分值两倍                    |
| 六个同点数 | "五个同点数"的分值两倍                    |

（10pt）

**输入格式**

输入若干行，每行为一个长度固定为6的字符串（用字符`'1'`~`'6'`表示点数），表示本次投掷的结果。

**输出格式**

对于每一行输入，输出一行表示本投掷结果可以结算出的最大得分。

#### T4

显然`x` `y`不存在时，当且仅当`a % b == 0 || b % a == 0`，特判输出`0 0`。

由于`x` `y`独立，则`x+y`最小等同于`x` `y`均取最小，对`a` `b`分别扩倍并取第一个满足条件的值即可。

记得开`long long`。

#### T5

本人考场做法，不排除有更优解。

对于数列 `A = { a, b, c, d }`，`f(A) = |a-b| + |b-c| + |c-d|`。注意到，除了首尾元素，删去中间的元素会使`f(A)`的展开表达式中固定地移去两项再加上一项（例如移去`|a-b| + |b-c|`，新增`|a-c|`），维护此固定变化的极值，再单独特判删首项或删尾项的情况，即可求`f(A')`最大或最小值。

读入的同时预处理数组。读入结束后，即获得`f(A')`最小值，再遍历一遍把符合条件的删数下标存`queue`里，接着输出队列长度再输出队列内容即可AC。

记得开`long long`。

#### T6

第一眼看到觉得有坑，事实上就是看图写话，按图表翻译成代码即可。

显然出现3个以上相同点数时，就不可能出现5个以上连续点数，且枚举得连续点数和相同点数的结算方式一定优于单个点数（1和5）的结算方式，那还说啥了，先把特殊规则按计分优劣性从高到低扣了，剩下的有1或者5的就一股脑加上去完事。

注意别计算特殊规则的时候移去所有的`1`或`5`。

当时卡我最久的反而是这个输入方式，毕竟它没有指定测试数据组数，我原计划用`getchar()`逐字符读入，若为`\n`则计算分数并`memset`清空缓存，若为`EOF`则程序结束，若在`'0'`~`'9'`则减去`'0'`后存入固定大小为6的数组表示点数出现次数。神奇的事情发生了，PTA网站上那个测试框框里怎么测都正确，一提交“听取WA声一片”，又不能离开网站界面用本地文件输入调试。写完其他题目后想起来，怀疑测试样例有疑似空行的情况，或者`\n`以外换行符（猜测），反正加了保险以后交卷前踩点真就AC了。

## 笔者杂谈

大概NOIP省三水平即可AK本卷编程题，建议后来者打实基础，保证拿下类似填空第一题（只会用std::sort的有福了）的分数。个人感觉今年较去年（去年数智题目信息来自学长经验帖）来说难度有所下降，至少去年T5/T6考了点算法（二分和前缀和），今年题目更偏向于考察对编程语言的熟悉程度以及把思路变现的能力（**免责申明，仅个人理解，也可能完全不是这么回事**），对脑子灵活的初学者友好一些，当然前提是对语言和常用库保持熟悉。
